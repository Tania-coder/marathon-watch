# Copenhagen Marathon — Apple Watch

Apple Watch screens for the Marathon-2027 kiosk prototype.
The QR codes on the kiosk screens open these pages:

- Water station → `watch-water.html`
- Toilets → `watch-toilet.html`
- Equipment → `watch-equipment.html`
- First aid → `watch-location.html`

Start screen: `watch.html` (All locations).
